Library Management System

A simple Library Management System developed using the C programming language as a first-semester academic project.

Features

- Book management
- Issue and return books
- Student management
- Admin functionality
- File handling for data storage
- Menu-driven interface

Technologies Used

- C Programming Language
- Code::Blocks IDE
- File Handling

How to Run

1. Download or clone this repository.
2. Open "Library Management System.cbp" in Code::Blocks.
3. Build and run the project.

Project Type

First Semester CSE Academic Project.
